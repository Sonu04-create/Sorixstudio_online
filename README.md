## ✨ Features

- **⚡ Dynamic Pitch Engine**: Query parameter routing (`?id=<creator-slug>`) dynamically loads custom landing pages, tailored color accents, and customized call-to-actions.
- **🖼️ Local Asset Integration**: Custom founder branding featuring high-resolution avatars and curated media.
- **🔍 Project Category Filtering**: Filter work by **All Projects**, **Live SaaS Product**, or **Creator Concepts**.
- **📱 Live Interactive Modal**: Built-in modal viewer allowing instant live preview of external websites directly within the portfolio.
- **💬 Direct Founder Outreach**: WhatsApp, phone, and email action channels for instant collaboration with Sonu M.
- **💎 Premium Visual Aesthetics**: Glassmorphism, smooth CSS gradients, dark theme, interactive hover states, and micro-interactions.

## 💻 Local Development

### 1. Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/Sonu04-create/Sorixstudio_online.git

# Navigate to project directory
cd Sorixstudio_online

# Install dependencies
npm install
```

### 3. Start Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
